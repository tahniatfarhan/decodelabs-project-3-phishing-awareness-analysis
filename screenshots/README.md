# Screenshots

Empty on purpose — same policy as the other projects.

**Two easy ways to get real ones:**

1. Open the live preview Claude shared alongside this ZIP (or open `index.html` locally) and use your OS screenshot tool.
2. Paste each file from `../samples/` into the textarea, click **Analyze**, and capture:
   - `phishing-analysis.png` — using `suspicious-email-1.txt` or `suspicious-email-2.txt` (High Risk)
   - `legitimate-analysis.png` — using `legitimate-email.txt` (No obvious indicators)

Drop the files here with those names.
